Request

GET https://memecheck.pages.dev/api/v1/token?ca=<token address>&chain=solana
x-api-key: mck_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

ca — token mint / contract address. chain — solana | ethereum | bsc | base | arbitrum (default: solana for base58 addresses, ethereum for 0x). The key may also be sent as Authorization: Bearer mck_…. CORS is open, but keep keys server-side.

curl -s "https://memecheck.pages.dev/api/v1/token?ca=DezXAZ8z7PnrnRJjz3wXBoRgixCa6xjnB7YaB1pPB263&chain=solana" \
  -H "x-api-key: $MEMECHECK_KEY"

Limits & errors

401missing / invalid / revoked key
400bad address or chain
429rate limited (per minute, per UTC day, or live-check limit for tokens not cached yet) — see retry-after
503not cached yet and live data sources are busy — retry after the Retry-After header (~60 s)

Every response carries x-ratelimit-tier, x-ratelimit-remaining-day, x-ratelimit-remaining-minute. Counters are enforced per Cloudflare location (best-effort). Results are automated heuristics, not financial advice. Paid plans buy quota only — they never change any score.
