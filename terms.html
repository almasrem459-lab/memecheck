Terms: usage, ads & refunds

Last updated 2026-10-21.

Using the checker

  • MemeCheckShield is an automated, best-effort tool. It is not financial advice, not an audit, and not a guarantee. “No major red flags” does not mean safe: most fresh meme coins still fail (see /accuracy).
  • Data comes from third-party sources that can be wrong, late or down. Always do your own research.
  • Do not abuse the API endpoints (automated floods are rate-limited and may be blocked).

Sponsored placements and ads

  • Anything paid is labelled as sponsored. Paying never changes a token’s risk score, findings or level.
  • A sponsored placement is not an endorsement. We may refuse or remove a placement for a token that later shows critical risk (for example an active mint/freeze authority, honeypot or rug).

Refunds

  • If we cannot deliver a placement you paid for (for example we reject it before it goes live), we refund the full amount to the paying wallet.
  • If we remove a live placement because the token turned out to be a rug or honeypot, the unused time is not refunded.
  • Refund requests: use the feedback box below with the payment transaction signature within 14 days. On-chain payments are refunded on-chain in the same asset; network fees are not refunded.

Changes

We may update these terms; the date above changes when we do.
