1. How to read a MemeCheckShield scan

  1. Paste a Solana (or EVM) contract address on the home page.
  2. Wait for Low / Medium / High / Extreme. Extreme means a critical fail (e.g. active mint authority or confirmed honeypot).
  3. Read the reasons — each line is a pass / warn / fail with a weight. Full weights: /how.
  4. Check Developer history and the Dev Reputation Score (0–100). Serial launchers add risk. Lookup any wallet on /dev.
  5. Use bubble map, snipers, and liquidity flows as context — they are not the whole score.
  6. Low ≠ safe. Most fresh meme coins can still die. Always DYOR.

2. Why a flag fires (common cases)

  • Mint / freeze authority active — issuer can mint or freeze transfers → Extreme
  • Top holders / insider networks — few wallets can crash the price
  • Unlocked / thin LP — liquidity can be pulled
  • Serial launcher — same creator killed many prior coins
  • Honeypot / sell fail (EVM) — you may not be able to sell

3. Accuracy tracker (/rugs)

We score fresh Solana memes that meet entry rules and recheck 24h/48h later — all levels, not only High. RUGGED = −90% price/liq or pair gone. Daily tables and monthly report are automated. See /rugs and /report.

4. Telegram rug-alert bot (setup)

Watch a CA; get alerts on liquidity pull, large dev sell, or risk upgrade. Worker code is open source under alert-worker/.

  1. Message @BotFather → /newbot → copy the token.
  2. Store it as a Worker secret (never in git): cd alert-worker && wrangler secret put TELEGRAM_BOT_TOKEN
  3. Also set MEMECHECK_ORIGIN=https://memecheck.pages.dev (default).
  4. Deploy: wrangler deploy. Poll watches with external cron → POST /cron every ~5 min (Workers Free cron slots already full on this account).
  5. In Telegram: /start then /watch <CA>. Commands: /unwatch, /list, /help.

Status: the public MemeCheckShield Telegram bot is not live yet. Self-hosters can deploy it today with their own bot token.

5. Self-host

See GitHub → docs/SELF_HOST.md and docs/ENV.md. Infra notes: /infra.

1. كيف تقرأ نتيجة الفحص

  1. الصق عنوان العقد في الصفحة الرئيسية.
  2. النتيجة: منخفض / متوسط / مرتفع / أقصى. الأقصى = فشل حرج (مثل صلاحية سك نشطة أو مصيدة مؤكدة).
  3. اقرأ الأسباب — كل سطر نجاح / تحذير / فشل مع وزن. التفاصيل: /how.
  4. راجع سجل المطوّر ودرجة السمعة (0–100). ابحث عن أي محفظة في /dev.
  5. المنخفض ≠ آمن. ابحث بنفسك دائمًا.

2. لماذا يظهر التحذير

  • صلاحية سك / تجميد نشطة
  • تركّز الحاملين / شبكات المطلعين
  • سيولة ضعيفة أو غير مقفلة
  • مطلق متسلسل قتل عملات سابقة
  • مصيدة / فشل البيع (EVM)

3. متعقّب الدقة

نسجّل عملات سولانا الجديدة ونعيد الفحص بعد 24/48 ساعة لكل المستويات. الجداول اليومية والتقرير الشهري آلية: /rugs · /report.

4. بوت تيليغرام لتنبيهات السحب

  1. أنشئ بوتًا عبر BotFather واحصل على الرمز.
  2. سلّم الرمز لجوجو: wrangler secret put TELEGRAM_BOT_TOKEN داخل alert-worker/.
  3. الأوامر: /watch <CA> · /unwatch · /list.

الرمز غير موجود في هذا النشر. الكود والتوثيق جاهزان — اطلب الرمز من جوجو قبل التشغيل الحي.
