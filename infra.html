Infra, caching & rate limits (M2)

Honest notes on what runs today on free tiers, which env vars matter, caching we shipped to cut rate limits, and what a paid Helius / Cloudflare upgrade would unlock — only if Jojo approves spend. No secrets in this page.

ملاحظات صريحة عمّا يعمل اليوم على الخطط المجانية، ومتغيرات البيئة، والتخزين المؤقت لتقليل حدود المعدل، وما الذي تفتحه ترقية Helius / Cloudflare المدفوعة — فقط إذا وافق جوجو على الإنفاق. لا أسرار في هذه الصفحة.

What runs today (free tier)

  • Cloudflare Pages + Functions — site + APIs at memecheck.pages.dev
  • Workers KV (MEMECHECK_CACHE) — shared scan cache with a hard ~880 writes/day budget guard
  • Cache API — free per-colo hot copies for proxy, deep checks, snipers, flows, holders, AI, accuracy
  • Helius — HELIUS_KEY Pages secret (present). Free/dev plan; used for RPC + DAS fallback when pump.fun is blocked. Public Solana RPCs remain fallbacks.
  • No paid spend invented — this milestone documents unlocks; Jojo must approve any upgrade.

Caching improvements shipped (M2, free)

  • Longer edge TTLs on the allowlisted proxy: pump.fun 20→60s, RugCheck/GoPlus/Honeypot 120→180s, DexScreener 30→45s, GeckoTerminal 60→90s — stale-while-error already kept up to 24h
  • DevRep LP sample strengthened: up to 5 RugCheck reports on graduated priors (was 2)
  • Accuracy JSON + /api/accuracy cached 5 min at the edge
  • Existing: soft-degrade (never raw 429) on snipers/flows; Helius stampede mark; KV write budget guard

What paid plans would unlock (not purchased)

  • Helius Developer / Business — higher RPC RPS, webhooks for liquidity pulls & large transfers (needed for always-on Telegram alerts), reliable DAS for serial-launcher indexing, tx tracing for dev sell speed and funded-wallet graphs
  • Cloudflare Workers Paid — more CPU time, higher KV ops, Durable Object alarms without free-plan jitter, better for alert-worker cron
  • Cloudflare KV / R2 — larger launch index for Solana-wide DevRep (M1 gap: funded wallets / sell speed / linked supply)

Status: free tier only until Jojo approves spend. Docs + caching ship now so reviewers see the path.

ما يعمل اليوم (خطة مجانية)

  • Workers KV — كاش مشترك مع حد كتابة يومي
