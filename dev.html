Dev Reputation Scoreدرجة سمعة المطوّر

Paste a Solana token-creator wallet (or a mint CA). Get a 0–100 score with label Builder / Neutral / Serial Launcher / High Risk and the evidence behind it. Free, open JSON API.الصق محفظة منشئ عملة على سولانا (أو عنوان عقد). احصل على درجة من 0–100 مع التصنيف بنّاء / محايد / مُطلق متسلسل / خطر مرتفع والدليل خلفها. مجانًا، وواجهة JSON مفتوحة.

Open APIواجهة برمجة مفتوحة

GET /api/devrep?wallet=<pubkey>
GET /api/devrep?ca=<mint>

Returns JSON: score, label, components, evidence, gaps. Same dead/rugged rules as Developer history. Methodology: /how#devrep.يعيد JSON: الدرجة، التصنيف، المكوّنات، الأدلة، والفجوات. نفس قواعد الميت/المسحوب في سجل المطوّر. المنهجية: /how#devrep.
