# memecheck-smart (Smart money worker)

Feeds `/smart.html` via `/api/smart`. Research only: no keys, no signing, no trades. The track record is a paper simulation.

* **Scheduler:** a SQLite-backed Durable Object (`SmartDO`) re-arms its own alarm every ~2 min. (The free plan's 5 cron triggers are already in use.) One pipeline step runs per alarm invocation, which keeps each one under the free 10 ms CPU / 50 subrequest limits.
* **Pipeline:** discover → derive → probe → verify → build → risk.
  * **discover:** trending coins from Jupiter's public lists, filtered to meme coins.
  * **derive:** associated token accounts for the top 30 weighted wallets × 30 hot coins.
  * **probe:** `getMultipleAccounts` on a public RPC.
  * **verify:** signature check (airdrop filter).
  * **build:** weighted consensus plus the paper picks.
  * **risk:** the MemeCheck verdict, from the site's KV cache or a local `analyze()`.
* **Storage:** working state lives in the DO. The snapshot is published to KV key `smart:v1` every ~10 min, about 144 KV writes/day.
* **Endpoints:** `GET /smart.json` and `GET /status`.
* **Wallets:** `src/wallets.js` is generated by `gen_wallets.py` from the paper bot's wallet-quality model. It contains public leaderboard addresses and labels only.
* **Secrets:** none required. If you add an RPC key, use `wrangler secret put` and never commit it.

Deploy: `npx wrangler deploy` (from this folder).
